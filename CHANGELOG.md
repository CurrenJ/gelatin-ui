# Changelog

## 1.0.40

Fixed clicks near the right edge of the screen being ignored on Minecraft 26.1.2. An invisible page scrollbar caught clicks, hover and the mouse wheel there even on screens that don't scroll, so buttons and scrollbars under it stopped responding. It now only takes input while the screen can actually scroll.

## 1.0.39

No functional changes on Minecraft 26.1.2. This version keeps Gelatin UI aligned across its supported Minecraft releases.

## 1.0.38

Added Forge support for Minecraft 26.1.2 alongside Fabric and NeoForge.
